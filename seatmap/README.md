# 楼层工位图（seatmap）

> 完整文档（功能、部署、项目结构、开源依赖）见仓库根目录 [`../README.md`](../README.md)；本文为应用级速查。

可视化楼层工位布局系统：顶栏切换楼层 / 搜索工位，画布可拖拽编辑控件与工位，支持自定义属性、Excel 导入与身份验证，布局保存在服务端 JSON 文件中。

## 快速开始

```bash
cd seatmap
npm install

# 1) 用合成示例表生成初始布局（写入 server/data/layout.json）
npm run seed -- "samples/seatmap-sample.xlsx" --force
#    或用自己的工位表：npm run seed -- "..\你的工位表.xlsx"（先不加 --force 仅预览）

# 2) 开发模式（前端 5173，接口代理到 8787）
npm run dev:server      # 终端 A：后端 API
npm run dev             # 终端 B：前端

# 3) 生产模式（一条命令即可，构建产物由后端托管）
npm run build
npm start               # 打开 http://127.0.0.1:8787
```

默认口令 `admin123`，可用环境变量覆盖：

```bash
set SEATMAP_PASSWORD=你的密码
set PORT=8787
set SEATMAP_USER=admin
```

## 功能对照

1. 顶栏：楼层切换（编辑模式下可「＋楼层」新增、双击重命名、✕ 删除）、搜索框（跨全部楼层搜索，支持单个搜索 / 批量搜索，回车搜索具体属性，Esc 清空）、命中数量、工位总数（可展开明细统计）、缩放/适应、编辑模式开关。
2. 统计明细：点击工位总数展开——总数 / 已分配（有机器SN）/ 未分配（无机器SN）/ 空位 / 文本区控件，并按区域与全部楼层分组统计。
3. 工位显示：每个工位只显示一行信息；编辑模式下可用左侧编辑栏「显示属性」下拉全局指定显示哪个属性（座位号 / 机器SN / 网口号 / 任一自定义属性），设置会随布局一起保存。
4. 编辑模式：进入后左侧出现分类编辑栏（控件操作 / 批量编辑 / 历史记录 / 显示与吸附 / 数据导入），右侧属性面板负责选中控件或工位的精调；支持自动吸附开关、批量编辑开关、添加控件（放在当前视野的空白处）、复制/粘贴（Ctrl+C / Ctrl+V，粘贴到附近空位）、整理布局、撤销/重做（Ctrl+Z / Ctrl+Shift+Z）、导出模板、导入 Excel、保存布局（均需身份验证）。
5. 对齐辅助线：拖动控件时显示对齐虚线并按边吸附；**拉伸控件时同样有吸附辅助线**，可让宽/高与相邻控件对齐一致；可全局开关，也能在右侧面板对单个控件关闭。
6. 控件：显示文本、主题色、列数/行数、座位号前缀；未添加座位时只显示居中文案（修改文案不会改变控件尺寸）；在画布上拉伸带座位的控件会按新长宽自动计算行列数、自动增减工位；宽高不设下限（最小 2 个单位）。
7. 工位：座位号、机器SN、网口号 + 任意自定义属性；空位（未编号格子）在编辑模式下会显示「＋」，点击即可单独添加工位，已有工位可一键「清空」变回空位（自由增删）；工位可拖拽互换（含拖到空位）；无机器SN 的工位标记为「未分配」并计入统计。
8. 批量编辑：开启后可在画布空白处框选（或点击加选）多个控件，右侧面板提供批量删除、批量主题色、统一宽度/高度、统一宽高（最大/首个）、**横向/纵向间隔一致**与六向对齐；直接拖动任一选中控件即可**整体平移**选中控件（带吸附辅助线）。
9. 搜索：单个搜索把整段输入当作一个查询词，批量搜索按「换行分隔」（可粘贴文本编辑器 / Excel 复制的一列）拆分查询词并去重匹配；命中按「子串精确命中（强）/ 模糊相似（弱）」分级，画布上以洋红（强）/ 浅洋红（弱）统一高亮，右侧给出跨楼层结果列表；单个搜索的精确命中会自动切换楼层、居中放大，批量搜索会自动聚焦强命中区域放大（无强命中则适配全部命中区域）。
10. 悬停详情：查看模式下鼠标悬停工位会高亮并弹出浮窗，显示座位号、区域、机器SN、网口号与全部自定义属性。
11. 控件永不重叠：新增控件自动找空位；拖动重叠时自动互换位置；手改数值期间不自动位移，改完统一检测重叠并提示（可一键「自动错开」）；「整理布局」一键消除全层重叠。
12. 导入：先选基准属性（座位号 / 机器SN / 网口号 / 自定义属性）→「模板」导出以该属性为基准、含其他属性列的表格 → 填写后导入 → 对比视图逐行展示「现状 → 导入值」（将更新/无变化/未匹配分组、新增字段提示）→ 确认后才写入并用表格值覆盖其他属性。
13. 安全：登录签发 JWT（8 小时），保存布局 / 确认导入等敏感操作需二次验证（5 分钟有效）；服务端接口级鉴权 + 写入前备份 `server/data/history/`。

## Excel 导入格式

第一行是表头，必须包含 `座位号` 或 `工位号` 列；其它列按表头名匹配：

- `主机SN` / `机器SN` / `SN` → 机器SN
- `网口号` / `网口` / `端口号` → 网口号
- 其余列 → 该工位的自定义属性（不存在则自动添加）

也支持 `.csv`。推荐流程：编辑模式 → 「模板」下载以座位号为准的表格 → 填写 → 「导入 Excel」→ 在对比视图里确认后写入。

接口：`GET /api/template?floorId=&keyField=`（按指定基准属性导出模板）、`POST /api/import/preview`（上传并对比，支持 `keyField`，不写库）、`POST /api/import/apply`（二次验证后写入）。

## 目录结构

```
seatmap/
  index.html
  vite.config.ts
  src/
    App.tsx                      # 应用外壳、鉴权流程、保存/导入编排
    store.ts                     # zustand 状态 + 撤销/重做（快照式）
    types.ts                     # 数据模型（Floor / Block / Seat / SeatField）
    lib/layout.ts                # 几何计算（单元格尺寸、自动尺寸、座位栅格）
    lib/fuzzy.ts                 # 强弱命中搜索
    lib/api.ts                   # 后端接口封装
    components/Toolbar.tsx       # 顶栏（楼层 / 搜索 / 统计 / 视图与保存）
    components/EditBar.tsx       # 左侧分类编辑栏（仅编辑模式）
    components/FloorCanvas.tsx   # Konva 画布（控件/工位/高亮/拖拽/缩放）
    components/InspectorPanel.tsx# 右侧精调面板
    components/PasswordDialog.tsx
  server/
    index.js                     # Express + JWT + 布局读写 + Excel 导入
    data/layout.json             # 布局数据（运行时生成）
    data/history/                # 保存前自动备份（保留最近 10 份）
  tools/build-seed.mjs           # 从 Excel 生成初始布局
```

## 技术选型

- 前端：React 18 + TypeScript + Vite，画布用 `konva` / `react-konva`（Canvas 2D，缩放平移流畅，千级工位不卡）。
- 状态：`zustand`；撤销/重做为快照式历史（上限 60 步），仅在编辑模式生效。
- 布局几何：统一的座位格 `84×52`、间距 `10`、内边距 `14`、标题栏 `30`，位置吸附 `10px` 网格；防重叠采用"螺旋就近找空位"（`findFreeSpot`），全层整理用 `resolveOverlaps`。
- 搜索：`fuse.js`（强命中阈值 0.12，弱命中阈值 0.32，另叠加子串强命中），命中后通过 `seatmap:focus` 事件驱动画布定位。
- 后端：Node.js + Express + `jsonwebtoken` + `bcryptjs` + `multer` + `exceljs`，布局以 JSON 落盘并保留历史备份。

## 调试入口

浏览器控制台可用 `window.__seatmap` 访问 `store`（zustand）、`Konva`、`getStage()` / `getLayer()`，便于自动化测试与排查。

```js
__seatmap.store.getState().doc.floors[0].blocks.length;
```
